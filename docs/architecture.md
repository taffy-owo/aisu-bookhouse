# 项目结构

浏览器通过 /api/v1 与 FastAPI 通信；静态站点与 API 在生产环境通常通过同一个 HTTPS 域名提供。

- src/modules：按书库、上传、阅读器、翻译、账号与管理功能组织前端。
- src/shared：API 边界、主题、基础组件和工具。
- backend/app/modules：对应的业务模块、模型、权限与文件处理。
- backend/alembic：数据库版本迁移。
- backend/app/modules/uploads/worker.py：上传处理、翻译任务与来源更新的独立 worker。

原始图书、解析后的章节/封面与运行状态写入配置的存储目录；数据库保存账号、元数据、任务和阅读记录。下载与阅读通过鉴权 API 提供。模型密钥在后端加密存储或从服务器环境读取。

前端阅读主题与站点主题分别记忆；PDF 原页的纸色与亮度只改变显示，不改写原文件。听书音频仅在播放流程中临时使用。

开源快照保留应用与测试，排除私人服务器拓扑、一次性迁移/修复脚本、调试产物、第三方私人预设与旧运维历史。
