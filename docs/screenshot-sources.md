# 截图素材说明

README 图片由本项目实际前端在本机演示环境中截取。书名和作者对应真实作品；账号、阅读进度与统计为演示数据，没有使用私人账号或线上书库。新部署的书架默认为空。

截图使用项目维护者提供的五张封面图片，分别对应：

| 作品 | 作者 |
| --- | --- |
| 傲慢与偏见 / Pride and Prejudice | Jane Austen |
| 飘 / Gone with the Wind | Margaret Mitchell |
| 小妇人 / Little Women | Louisa May Alcott |
| 简·爱 / Jane Eyre | Charlotte Brontë |
| 百年孤独 / Cien años de soledad | Gabriel García Márquez |

封面仅作为界面展示素材出现在截图中，按实际书架容器缩放显示；原始封面文件和完整电子书不随仓库分发。封面图像的权利归相应权利人，本项目的 MIT 许可不适用于这些封面图像。

阅读页节选 Charlotte Brontë 的 *Jane Eyre* 第一章英文原文，来源 [Project Gutenberg，电子书 #1260](https://www.gutenberg.org/ebooks/1260)。此处未使用现代译本正文，也没有附带完整电子书文件。
